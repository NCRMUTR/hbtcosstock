## 2. หัวตารางซ้อน 3 ชั้น — ห้าม fix เลขแถว

ตัวอย่างชีต `Cosmetic JE` (ตัวเลขคือดัชนีคอลัมน์ เริ่มจาก 0):

```
แถว 5   1:Item    2:Description   3:Quantity              5:Unit price  6:Amount
แถว 6   1:ลำดับ                   4:หน่วยนับ    5:หน่วยละ   6:จำนวนเงิน
แถว 7   1:ที่      2:รายการ        3:จำนวน                  5:บาท        6:บาท
แถว 8   1:1       2:Xanthan Gum…  3:4          4:ขวด      5:54         6:216   7:LAB Serum
```

**ตำแหน่งต่างกันในแต่ละชีต** — `AnalCosmetic NC` หัวตารางอยู่แถว 3–5 และเริ่มที่คอลัมน์ 0
ส่วนชีตอื่นอยู่แถว 5–7 เริ่มที่คอลัมน์ 1

วิธีที่ถูกต้อง: **ไล่หาแถวที่มีคำว่า `รายการ` และ `จำนวน` อยู่ด้วยกัน** แล้วถือว่าแถวนั้น
คือหัวตารางชั้นล่างสุด จากนั้นจับคู่คอลัมน์จากข้อความในหัวตารางทั้ง 3 แถว ไม่ใช่จากเลขคอลัมน์ตายตัว

| ความหมาย | คำที่ใช้หา |
|---|---|
| ลำดับ | `ที่` / `ลำดับ` / `Item` |
| ชื่อรายการ | `รายการ` / `Description` |
| จำนวน | `จำนวน` / `Quantity` |
| หน่วยนับ | `หน่วยนับ` |
| ราคาต่อหน่วย | `หน่วยละ` / `Unit price` |
| จำนวนเงิน | `จำนวนเงิน` / `Amount` |

## 3. คอลัมน์ท้ายตารางไม่มีมาตรฐาน — ต้องเดาจากเนื้อหา

หลังคอลัมน์ "จำนวนเงิน" แต่ละชีตใส่ข้อมูลเพิ่มไม่เหมือนกัน และบางชีต**ไม่มีหัวตารางกำกับเลย**:

| ชีต | คอลัมน์ถัดไป |
|---|---|
| AnalCosmetic NC | วิชา · ปฏิบัติการ · ลิงก์ร้าน (มีหัวตารางครบ) |
| Perfumery PD 69 / Analchem NC | วิชา · ปฏิบัติการ · ลิงก์ร้าน (มีหัวตารางครบ) |
| ChemNatural Product TY | ชื่อแลป (`แลป 2`, `แลป 8`) · ลิงก์ร้าน — **ไม่มีหัวตาราง** |
| Cosmetic JE | ชื่อแลป (`LAB Serum`, `LAB Deodorant`) — **ไม่มีหัวตาราง** |
| Anti-aging Janny | ลิงก์ร้านอย่างเดียว — **ไม่มีหัวตาราง** |

กติกาที่ให้ใช้ เรียงตามลำดับ:

1. ถ้าหัวตารางบอกไว้ ใช้ตามหัวตาราง
2. ถ้าไม่มีหัวตาราง ให้ดูค่าในเซลล์:
   - ขึ้นต้นด้วย `http` หรือมีคำว่า `ร้าน` → **ลิงก์/แหล่งซื้อ**
   - ตรงแบบ `HBT` ตามด้วยตัวเลข 4 ตัว (เว้นวรรคได้ เช่น `HBT 2206`, `HBT2106`) → **วิชา**
   - นอกนั้นที่เป็นข้อความ → **ปฏิบัติการ**
3. ค่าวิชาอาจมีหลายวิชาในช่องเดียว เช่น `HBT 2206 และ 3211` → เก็บข้อความดิบไว้ทั้งก้อน
   อย่าเพิ่งแยก (รอบแรกยังไม่มีหน้าจอรายวิชา)

## 4. แถวที่ต้องไม่นำเข้า

- แถวหัวตารางทั้ง 3 ชั้น
- แถวที่คอลัมน์ "รายการ" เขียนว่า `รวม` (แถวสรุปยอดท้ายตาราง)
- แถวที่ไม่มีชื่อรายการ หรือไม่มีทั้งจำนวนและราคา
- แถวหัวกระดาษ `เอกสารแนบ 6 - 2` / `รายการวัสดุสาขาวิชาเทค…`

## 5. แปลงเป็นแถวในระบบอย่างไร

1 รายการในไฟล์ → **1 แถว Materials + 1 แถว Lots + 1 รายการ RECEIVE**

| ช่องในไฟล์ | ลงที่ |
|---|---|
| รายการ | `MATERIALS.INCIName` (ชื่อรายการ) |
| หน่วยนับ | `MATERIALS.Unit` |
| (เดาจากชื่อ+หน่วย) | `MATERIALS.ItemKind` |
| จำนวน | `LOTS.QtyReceived` + `Qty` ของรายการ RECEIVE |
| หน่วยละ | `LOTS.UnitPrice` |
| วิชา | `LOTS.Course` ← คอลัมน์ใหม่ |
| ปฏิบัติการ | `LOTS.LabSession` ← คอลัมน์ใหม่ |
| ลิงก์ร้าน | `LOTS.SourceLink` ← คอลัมน์ใหม่ |
| ชื่อชีต | `LOTS.OwnerName` ← คอลัมน์ใหม่ (อาจารย์เจ้าของรายการ) |
| — | `LOTS.FiscalYear` = ปีงบจากชื่อไฟล์ (2_68 → 2568) ให้ผู้ใช้ยืนยันได้ |

**จำนวนเงิน ไม่ต้องเก็บ** — คำนวณจาก จำนวน × ราคาต่อหน่วย ได้อยู่แล้ว
เก็บไว้จะกลายเป็นตัวเลขที่ขัดกันเองเมื่อมีการเบิกจ่าย

## 6. เดาชนิดของ แล้วให้คนยืนยัน

ห้ามเดาแล้วบันทึกเงียบ ๆ — หน้าตรวจก่อนนำเข้าต้องโชว์ชนิดที่เดาได้และแก้ได้ทีละแถว

แนวทางการเดา (ถูกประมาณ 80% พอให้คนไล่แก้ที่เหลือ):

- หน่วย `ขวด` `ถุง` `แกลอน` `ถัง` `กระป๋อง` → มักเป็น **CHEMICAL**
- ชื่อมีคำว่า `กระดาษ` `ถุงมือ` `cuvette` `tip` `หลอด` `แพ็ค` → **CONSUMABLE**
- ชื่อมีคำว่า `บีกเกอร์` `ขวดแก้ว` `ช้อนตัก` `ขาตั้ง` `เครื่อง` + หน่วย `อัน` `ใบ` `ชิ้น` `ชุด`
  → **EQUIPMENT**
- เดาไม่ได้ → ปล่อยเป็น CHEMICAL แล้วทำเครื่องหมายให้คนตรวจ

## 7. นำเข้าซ้ำต้องไม่เกิดของซ้ำ

ผู้ใช้จะเผลอกดนำเข้าไฟล์เดิมซ้ำแน่นอน — ใช้กุญแจกันซ้ำ = `ชื่อชีต + ชื่อรายการ + ปีงบ`
ถ้าซ้ำให้ข้ามและรายงานว่าข้ามกี่รายการ ไม่ใช่สร้างล็อตใหม่ทับ

## 8. เทสที่ต้องมี

- ชีตว่าง 3 ชีต ต้องข้ามโดยไม่ error
- `AnalCosmetic NC` (คอลัมน์เริ่มที่ 0) กับ `Cosmetic JE` (เริ่มที่ 1) ต้องอ่านได้ทั้งคู่
- แถว `รวม` ต้องไม่ถูกนำเข้า
- ชีตที่ไม่มีหัวตารางคอลัมน์ท้าย (`ChemNatural Product TY`) ต้องแยกลิงก์ออกจากชื่อแลปได้ถูก
- นำเข้าไฟล์เดิมซ้ำครั้งที่ 2 ต้องได้ของเพิ่ม 0 รายการ
- รวมทุกชีตแล้วต้องได้ ~86 รายการ (ยืนยันตัวเลขจริงอีกครั้งตอนเขียนเทส)
