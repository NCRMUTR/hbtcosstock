## เริ่มต้นอย่างไร

```bash
npm test            # ทดสอบหลังบ้าน 315 ข้อ บนตัวจำลอง Apps Script (ไม่ต้องติดตั้งอะไร)
npm run bundle      # รวม gas/*.gs 13 ไฟล์ → dist/Code.gs สำหรับวางใน Apps Script
npm run mock        # เปิดเซิร์ฟเวอร์จำลองพร้อมข้อมูลตัวอย่างที่ http://localhost:8799
npm run e2e         # ทดสอบหน้าเว็บจริงด้วย Chromium 117 ข้อ (ต้องมี playwright)
```

เปิดโฟลเดอร์นี้ใน Claude Code แล้วสั่งงานทีละข้อตาม `PLAN.md` ได้เลย

## สิ่งที่ระบบทำได้แล้ว (ยกมาจากระบบพี่น้อง ทดสอบแล้วทั้งหมด)

- **คลังและการเคลื่อนไหว** — รับเข้า · เบิกใช้ · คืน · ปรับยอด · จำหน่ายออก · ยกเลิกรายการ
  ยอดคงเหลือคำนวณจากบัญชีเดินสะพัดเสมอ ตรวจย้อนหลังได้ทุกบรรทัด
- **ที่เก็บเป็นลำดับชั้น** ห้อง → ตู้ → ชั้น → กล่อง พร้อมรูปถ่ายและปุ่มที่ลากวางบนรูปได้
- **รูปภาพ** ของที่เก็บ/ล็อต/สาร ถ่ายจากกล้องมือถือต่อเนื่องได้ ดูก่อนอัปโหลด หมุนรูปได้
- **ผู้ใช้ 2 ชนิด** บัญชี Google ขององค์กร และบัญชีรหัสผ่านสำหรับคนที่ไม่มีอีเมลองค์กร
  สิทธิ์ 3 ระดับ (admin / staff / viewer) ปิดบัญชีหรือเปลี่ยนสิทธิ์แล้วมีผลทันที
- **นำเข้า CSV** จากระบบเดิม พร้อมหน้าตรวจก่อนบันทึก
- **ค้นหาเร็ว** ทำดัชนีในเครื่อง พิมพ์แล้วกรองทันทีโดยไม่ยิงเซิร์ฟเวอร์
